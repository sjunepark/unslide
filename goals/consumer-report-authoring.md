# Consumer Report Authoring

Outcome: make Unslide a complete, intuitive report-authoring product without
weakening report ownership or its headless HTML-first architecture.

## State

Status: active. [The consumer-authoring plan](../plans/consumer-authoring-ergonomics.md)
is the current roadmap item. Goals 1 through 3 are delivered. Goal 4
implementation, validation, and code review are complete, with delivery pending.

## Included Scope

- Authoring and automation contracts in the product, design, architecture, and
  consumer-authoring plan.
- Dependable CLI results and diagnostics from Goals 1 and 2.
- Project setup and React authoring from Goal 3.
- Complete review and standalone-artifact workflows from Goal 4.
- Realistic onboarding and independent consumer proof from Goal 5, including
  the adjacent asset-impairment report without redistributing its protected
  source material.

Static or interactive report modes, a first-party gallery, fit or pagination
logic, accessibility auditing, development or doctor modes, visual scoring,
managed visual recipes, design systems, CSS-framework integration, and new
adapter or plugin seams remain excluded.

## Evidence

- The accepted implementation order, completion criteria, and deferred scope
  are maintained in the plan rather than duplicated here.
- The existing package and adjacent impairment-report consumer establish the
  starting behavior and the consumer-side orchestration that this goal removes.
- Each completed goal will record its validation and delivery evidence in the
  plan and its pull request.
